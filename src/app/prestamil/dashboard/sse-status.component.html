Objetivo: Verificar que al iniciar sesión en otra PC con el mismo usuario, la primera PC reciba un evento "force-logout" y cierre sesión inmediatamente.
Requisitos previos:
  • Backend configurado con Spring Session JDBC
  • Endpoint SSE GET /auth/stream/logout implementado
  • Lógica de detección de login duplicado en backend
  • Dos navegadores o dos ventanas de incógnito
Pasos de prueba:
  1. PC 1 (o Navegador 1):
    • Inicia sesión con usuario user1
    • Navega a esta página o deja el dashboard abierto
    • Verifica que el estado sea CONECTADO
    • Deja esta ventana abierta y visible
  2. PC 2 (o Navegador 2 en modo incógnito):
    • Abre el navegador y ve a http://localhost:4200/login
    • Inicia sesión con el mismo usuario user1
    • El backend debe detectar que user1 ya tiene sesión activa en PC 1
    • El backend debe emitir evento SSE force-logout a PC 1
  3. Resultado esperado en PC 1:
    • Inmediatamente (en menos de 1 segundo) recibe evento force-logout
    • La sesión se cierra automáticamente
    • Redirige a /login con mensaje: "Sesión revocada: nuevo inicio en esta sucursal"
    • En el historial de eventos aparece: FORCE-LOGOUT
Verificación en consola del navegador:

Abre DevTools (F12) en PC 1 y busca estos logs:

[AuthStreamService] Evento force-logout recibido: ...

Nota: La reconexión automática está configurada con backoff exponencial (máximo 5 intentos: 2s, 4s, 8s, 16s, 32s).
Endpoint SSE en el backend:
@RestController
@RequestMapping("/auth")
public class AuthController {{"{"}
    private final Map<String, SseEmitter> emitters = new ConcurrentHashMap<>();

    @GetMapping("/stream/logout")
    public SseEmitter streamLogout(@RequestParam String username) {{"{"}
        SseEmitter emitter = new SseEmitter(Long.MAX_VALUE);
        
        // Si ya hay un emitter para este usuario, enviamos force-logout
        SseEmitter oldEmitter = emitters.put(username, emitter);
        if (oldEmitter != null) {{"{"}
            try {{"{"}
                oldEmitter.send(SseEmitter.event()
                    .name("force-logout")
                    .data("Nuevo login detectado en otra PC"));
                oldEmitter.complete();
            {"}"} catch (Exception e) {{"{"}
                // El cliente anterior ya estaba desconectado
            {"}"}
        {"}"}
        
        emitter.onCompletion(() -> emitters.remove(username));
        emitter.onTimeout(() -> emitters.remove(username));
        emitter.onError(e -> emitters.remove(username));
        
        return emitter;
    {"}"}
{"}"}
